# 🚀 NEVER ENDING GAME

## 🎮 About
**Never Ending Game** is an endless space shooter built using **Python 🐍** and **Kivy 🎨**.

![Space](space.png)

## 🛠️ Built With

![Python](python.png)

### 🐍 Python
Used for the game logic, enemy spawning, bullets, collision detection, score, lives, and difficulty system.

![Kivy](kivy.png)

### 🎨 Kivy
Used for the game interface, touch controls, images, buttons, labels, and timers.

## ⚡ Features
- 🚀 Move the spaceship by dragging
- 🔫 Automatic shooting
- 👾 Endless enemy spawning
- ❤️ 3 lives
- 🏆 Score system
- ⚡ Increasing enemy speed
- 🔥 Increasing bullet speed
- 👾 Increasing enemy bunch size
- 🔄 Restart system
- ♾️ Endless gameplay

## 📈 Difficulty System

| Feature | Starting Value | Increase |
|---|---:|---:|
| 👾 Enemy Speed | 200 | +50 every 8 seconds |
| 🔫 Bullet Speed | 500 | +60 every 2 seconds |
| 👾 Enemy Bunch | 3 | +1 every 20 seconds |
| 🏆 Score | 0 | +1 per enemy |

## ❤️ Life System
You start with **3 lives ❤️❤️❤️**.

Every enemy that escapes costs one life.

At 0 lives → **💀 GAME OVER**

## 🏆 Score System
Destroying an enemy gives **+1 score**.

Every **200 points**, the enemy bunch increases by 1.

## 🕹️ Controls
📱 Touch and drag the spaceship **left or right**.

## 🔄 Restart System
After Game Over:
- ❤️ Lives reset to 3
- 🏆 Score resets to 0
- ⚡ Enemy speed does NOT reset
- 🔫 Bullet speed does NOT reset
- 👾 Enemy bunch size does NOT reset
